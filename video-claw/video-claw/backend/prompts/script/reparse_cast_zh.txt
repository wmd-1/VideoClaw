你是剧本人物/场景连续性分析器。只根据变更集正文和现有清单，输出更新后的候选人物与场景。

【变更集正文】
{changed_episodes}

【现有候选人物】
{characters}

【现有候选场景】
{settings}

要求：
1. 只输出纯 JSON 对象，不要 Markdown 或解释。
2. characters/settings 都是数组；每项至少包含 name，可包含 description、species、asset_kind（人物）或 description、mood、asset_kind、aliases（场景）。
3. 不要输出 character_id、setting_id、id、selected、versions、status、description_owner、description_source 等运行时字段。
4. 保留正文中仍存在的人物/场景；新增项写入数组。不要仅因变更集未提及就删除现有项。
5. 人物描述只写客观静态视觉特征；场景描述只写空间、光照和核心陈设。
6. 旁白/画外音不作为人物。

输出格式：
{{
  "characters": [
    {{"name": "人物名", "description": "客观描述", "species": "人类", "asset_kind": "human"}}
  ],
  "settings": [
    {{"name": "场景名", "description": "客观描述", "mood": "氛围", "asset_kind": "place", "aliases": []}}
  ]
}}
