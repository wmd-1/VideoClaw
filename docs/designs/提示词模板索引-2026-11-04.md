# 提示词模板索引（D5）

- 状态：**索引完成（2026-11-04）**
- 范围：`backend/prompts/` 下的模板族与调用入口；本索引只记录，**无引用不等于可删除**。
- 加载规则：`load_prompt(category, name, lang)` 依次尝试 `{name}_{lang}.txt` → `{name}_zh.txt` → `{name}.txt`；`load_prompt_with_fallback` 先首选语言、再回退 zh。

## 三、维护约定

- 新增/删除模板必须同步本索引与 `test_prompt_call_sites_contract.py`；
- 直接调用点新增时必须提供全部占位符，测试会对 AST 中的 `format` 调用做静态核对；
- 语言回退只说明“可加载”，不代表内容已本地化；
- 无引用模板只标记“未引用”，删除需单独评审。
