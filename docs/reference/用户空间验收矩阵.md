## 后端测试

```bash
# 测试目录复制到既有容器（compose 未挂载 tests）
docker exec video-claw-backend rm -rf /app/tests
docker cp video-claw/video-claw/backend/tests video-claw-backend:/app/tests
docker exec -i -e PYTHONPATH=/app -w /app video-claw-backend \
  /app/.venv/bin/python -m pytest tests -q
```
